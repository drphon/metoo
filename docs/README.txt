TodoClock - ویجت ساعت، کارها و پروژه ها برای ویندوز

دو نسخه هست:
1) TodoClock.zip (حدود ۶۰ مگ): نسخه کامل. هیچ چیز دیگه ای لازم نداره.
2) TodoClock-small.zip (کمتر از ۱ مگ): نسخه سبک. باید .NET 8 Desktop Runtime (x64) روی ویندوز نصب باشه:
   https://dotnet.microsoft.com/download/dotnet/8.0
   (بخش .NET Desktop Runtime 8، نسخه Windows x64). اگه نصب نباشه، خود برنامه موقع اجرا لینک دانلودش رو نشون میده.

اجرا: روی TodoClock.exe دو بار کلیک کن. اگه ویندوز هشدار SmartScreen داد: More info و بعد Run anyway.

کار با ساعت:
- کشیدن با موس: جابجا کردن ساعت به هر جای صفحه
- دو بار کلیک روی ساعت یا دکمه کوچیک پایینش: باز کردن پنل
- دکمه بالا سمت راست پنل یا Esc: جمع کردن
- چرخ موس روی ساعت: کم و زیاد کردن شفافیت
- کلیک راست: منو (اجرا با روشن شدن ویندوز، پنهان کردن، خروج)
- آیکون کنار ساعت ویندوز (System Tray): نمایش / پنهان و خروج
- عدد روی ساعت جمع شده: کارهای مانده امروز (اگه کاری عقب افتاده باشه قرمز میشه)

تب کارها: کارهای روزانه. بنویس و اینتر بزن.

تاریخ انجام (برای همه کارها):
- دکمه تقویم کنار جای نوشتن: قبل از اضافه کردن، تاریخ کار رو انتخاب کن
- روی هر کار موس رو ببر و دکمه تقویمش رو بزن، یا روی تاریخ خود کار کلیک کن
- انتخاب سریع: امروز، فردا، هفته بعد، یا یه روز از تقویم شمسی؛ «بدون تاریخ» تاریخ رو برمیداره
- کار امروز با رنگ اصلی، کار عقب افتاده قرمز نشون داده میشه
- دکمه «ترتیب تاریخ» پایین لیست: مرتب کردن کارها بر اساس تاریخ

تب پروژه ها:
- اسم پروژه (مثلا اسم یه سایت) رو بنویس و اینتر بزن
- روی پروژه کلیک کن تا کارهاش رو ببینی، اضافه، تیک یا پاک کنی؛ با دکمه فلش برگرد
- تغییر اسم: دکمه مداد (یا مداد روی کارت پروژه)؛ پاک کردن: دکمه ضربدر روی کارت (موس رو روی کارت ببر)
- روی هر کارت تعداد کارهای مانده نوشته شده

تب تقویم:
- روزهایی که کار دارن یه نقطه دارن (قرمز یعنی عقب افتاده)
- روی هر روز کلیک کن تا کارهای اون روز از همه لیست ها رو ببینی، یا برای اون روز کار اضافه کنی

اطلاعات در %APPDATA%\TodoClock ذخیره میشه (data.json). لیست قبلی کارها خودکار منتقل شده و یه نسخه پشتیبان (todos.v1-backup.json) هم کنارش هست.
